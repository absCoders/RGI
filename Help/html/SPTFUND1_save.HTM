Fund Codes

This screen is used to maintain records in the Fund Codes table.
Please click here for general help with the operation of any File Maintenance screen.


A Fund Code is used in a contract to identify the relationship between the contracted fund amounts and the Financials.

A Fund Code is defined for use in CPG or Commodity business, and must be used in one or the other type of business, and cannot be used in both.

When a fund amount is correlated to a sales order, if the fund is associated with Commodity business, it can be used to recover sales (or accrue money) for use when the fund is paid.

Prior to payment, a fund may be set up in a contract to be expensed on a specfic date, or else upon the 1st shipment. When the expense is accrued, it occurs using the Expense and Accrual accounts defined to that specific fund (code).

When the fund is paid, it may be paid either through AR (via a Customer Credit On Account) or else through AP (via an AP Check).

FieldDescription
Acct Code AccrContains the GL Account used to accrue amounts open in contracts defined using the associated Fund Code.
Acct Code RecContains the GL Account used to recover (ie accrue) fund money against volume.
Fund Accr On ShipmentIndicates whehter amounts defined using this fund code should be expensed/accrued upon shipment.  The alternative is that the fund amounts are expensed/accrued using the starting date of the contract.
Fund Brkr Comm

Indicates whether fund amounts are to be charged back to broker commissions. This indicator is no longer in use.

Fund Usage DescContains an expanded description for how this fund code is expected to be used.
Market TypeContains the Market Type for which this fund is intended to be used.  There are different rules and algortihms in place for expensing and recovering fund amounts, based on the Market Type.
