Marketing Program Codes

This function is used to maintain codes and description for Marketing Programs.

Marketing Program Codes are assigned to Rebate Details in the Sales Contract Maintenance Function.

Sales Invoice & Credit Memo activity recorded against rebate contracts may then be aggregated by Marketing Program Code to see an analysis of all rebate expenditures against a specific Marketing Program.  The assignment of Rebate Contract details to a single Marketing Program Code provides a means of aggregating multiple sales contract rebate details into a single program for analytic purposes.
