MRTABCP1 : ABC Parameters

This table is used to store Planning Parameters related to ABC Rankings, for use in setting default values to Items after calculating an item's ABC value.

Please review General Notes for Single-Record Table Maintenance for features which are common to all Single-Record Table Maintenance functions.

Overview

Each record in this table represents a consecutive range of items which have been ranked using Run-Time Options selected when running the ABC Classification Report.  Usually, the ranking criteria is "Cost Throughput", where the total demand (forecasted plus production) is extended by the item's standard cost, and then all items are ranked according to their cost throughput (usually within brand) with the item having the highest cost throughput appearing on the top of the list (for each brand).  The running total for the items is calculated from the 1st through the last item (within brand), and the report is segmented when the running total is greater or equal to the percentage of the total for cost throughput reflected by the percentage attributed to the A items, then next to B items, and so forth, until each item in the list is assigned an ABC ranking.

There may be more than just 3 records in this table (i.e., 6 classes may be defined by A,B,C,D,E & F).  The codes are alphanumerically sorted to determine their relative priority, and the Pct Range is used to determine how much of the total cost throughput belongs to that code.

If the sum of the %'ages in each of the Pct Range fields adds up to more than 100, the total is prorated back to 100% and the rounding remainder (if any) is apportioned to the 1st code.

Table Columns

ABC Code (ABC_CODE, alpha, 1 character)

Usually, this field will contain an A, B, or C, but other values may be used to extend the ABC classification beyond just 3 ranked groups.

Description (ABC_DESC, alphanumeric, 20 characters)

Contains the description for a particular ABC Code.  Usually, this field contains an unimaginative description (such as "A items", "B Items", etc.).  A items are sometimes referred to as the "Turners and Burners"

Max Position (ABC_MAX_POS, numeric, formatted 99, range from 0 thru 99)

Contains the value for Max Position that will be assigned to items belonging to the ABC Code, defined above, during the update which follows the ABC Classification Report.  Once assigned to all items in the ABC class, this value may be changed for individual items using Item Master File Maintenance or the Planning Inquiry.

Min Position (ABC_MIN_POS, numeric, formatted 99, range from 0 thru 99)

Contains the value for Min Position that will be assigned to items belonging to the ABC Code, defined above, during the update which follows the ABC Classification Report.  Once assigned to all items in the ABC class, this value may be changed for individual items using Item Master File Maintenance or the Planning Inquiry.

Pct Range (ABC_PCT_RANGE, numeric, formatted 999, range from 0 thru 100)

Contains the size of the percent range belonging to the ABC Code, defined above.  For example, if this value is "20" for ABC Code "A", then then "A" items are defined as the items listed in the top 20% of the total cost throughput, when running the ABC Classification Report; if this value is "30" for ABC Code "B", then the "B" items are defined as the items listed in the next 30% of the total cost throughput, when running the ABC Classification Report.

Minimum Days of Supply (ABC_MIN_DAYS_SUPPLY, numeric, formatted 999, range from 0 thru 999)

Contains the value for Minimum Days of Supply that will be assigned to items belonging to the ABC Code, defined above, during the update which follows the ABC Classification Report.  Once assigned to all items in the ABC class, this value may be changed for individual items using Item Master File Maintenance or the Planning Inquiry.  This value may be either working days, or calendar days, as defined yb the MR Parameters Record.
