Welcome to ABSolution.


ABSolution is a highly customized, and easily customizable, suite of business applications from Applied Business Systems, Inc.  Written entirely in Microsoft Visual Basic, and using some popular third party components, ABSolution developers use an advanced Development Environment, also provided by Applied Business Systems, Inc., to create tightly integrated business applications with high fidelity to the business processes they control.

The Applications are Developed with the following Products:

Microsoft Visual Basic (.Net CLR3.5)
Oracle Server (11g)
Crystal Reports (CR 2008)

The following 3rd party Components are used throughout ABSolution:

Infragistics NetAdvantage (.Net v10.3)
nSoftware Internetworking Components (for .Net)
Gembox Spreadsheet (v3.1)

Menu-Level Access

Menu items are associated with security codes (such as AP for Accounts Payable, AM for Accounting Management, and 01 for user group 01).  Users are assigned a list of such codes, defining which security codes are granted to the user.  When the user logs into ABSolution, the user's menu is built with only those menu items whose security codes are listed in the user's profile.  If none of a menu's security codes are in the user's security code list, then the entire menu is excluded from the user.  If a menu item has several security codes, and the user has at least one of them, then the menu item is included in the user's menu.

ABSolution Updates

When a developer compiles a new version of ABSolution and deploys it to the main ABSolution share, it will be automatically copied to each ABSolution user on their next log-on.  If a user is already logged into ABSolution, the only way to pick up the most recent version is to log out, and then log back in.  The process of logging in includes an update script, which will copy the most recently compiled and deployed components of ABSolution onto the user's workstation.
