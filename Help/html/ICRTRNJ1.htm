Microsoft HTML Help

Overview

Microsoft® HTML Help consists of an online Help Viewer, related help components, and help authoring tools from Microsoft Corporation. The Help Viewer uses the underlying components of Microsoft Internet Explorer to display help content. It supports HTML, ActiveX®, Java™, scripting languages (JScript®, and Microsoft Visual Basic® Scripting Edition), and HTML image formats (.jpeg, .gif, and .png files). The help authoring tool, HTML Help Workshop, provides an easy-to-use system for creating and managing help projects and their related files.

Features

  • The HTML Help components, which consist of an ActiveX control or Java Applet to insert into HTML files, a help authoring tool, an online image editing tool, and an executable program that displays a user's help files. GO
  • An authoring guide with sections on how to design a help system and how to use HTML Help Workshop. GO
  • References that contain information about the HTML Help ActiveX control, an HTML Help API reference for developers, a complete HTML tag reference, and reusable help topics that explain how to use the Help Viewer. GO
