Misc Charge Codes

This function is used to maintain Miscellaneous Charge Codes.  These codes are used to define the relationship between a charge (or credit) amount on an Invoice (or Credit) document, and the general ledger.

There may be one and only one Misc Charge Code associated with an Invoice (or Credit) document.

These codes are used in the following functions:

  1. (Debit/Credit) Memo Entry (aka Top Side entries)
  2. Statement Printing (Finance Charges, Fuel Surcharges, Monthly Freight, ECP Credits)
  3. Sales Order Processing (Misc Charges)
