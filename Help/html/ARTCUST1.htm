During the Period-End Process (i.e., after Period-End Initialization and before Period-End Finalization) you will be warned if you attempt to run this function after it has already been updated, in order to avoid duplicate entries in the General Ledger.  Also, at Period-End Finalization, you should check that this function is listed among those that have been update during the Period-End Process.

The update includes the following automated entries into the General Ledger:

  • Sales Journal
  • Cost of Goods Sold Journal
  • Inter-Company Shipments

 

The function may be run at any time, with the following general observations:

  • Standard Costs for a period are not locked in until Period-End Initialization had been performed and the Item Cost Re-Valuation Report has been updated; therefore, running these reports in the current period will reflect item standard costs from the prior period.
  • This function is part of the list of reports prepared during Period-End.  There is no update associated with this function except when running it as part of the Period End process.

User Interface

 

Run-Time Options

Report Period

Any prior period within the last 5 years may be selected.

If you select the current operations period, then the report will reflect the current month-to-date shipments; note that the final costs for the current month are not updated until Period End Processing had begun.

Selecting a prior period will render the prior period's shipments and returns for that month in total, using the costs which were in effect during that period.

This function uses the current relationships of customers to trade classes to markets, and items to brand to sales divisions. If any of those relationships are altered, a report printed after a period has been closed will use the new relationships, rather than those that were in place at the time that the Period was closed.

 

Costing Method

  • Standard Cost
  • Marketing Cost
  • SCP Cost

Report Sorting

There are no run-time sorting options.  Report sorts have been fixed programmatically.

Report Filtering

You may filter the report by indicating the inclusion of all, selected, or (all) except the following entities:

  • Sales Division
  • Customer
